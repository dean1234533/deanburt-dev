Questions

The details, clearly answered.

How access, code handling, AI reviews and billing work.

Will it change my code without asking?+

No. A fix is always a pull request on a new branch. Nothing changes until you review and merge it. Quick Scan First will not touch workflows or anything outside your repository.

What access does it need?+

A fine-grained GitHub token, limited to repositories you choose, with read and write access to Contents and Pull requests. You can revoke it at any time.

Is my source code stored?+

No. Code is read during a scan and is not saved on our servers. Relevant files are sent to Anthropic only when an AI review or fix needs them.

Does it work with private repositories?+

Yes, provided your fine-grained token has access to them.

Can the AI be wrong?+

Yes. Quick Scan First is a useful second pair of eyes, not a security audit or guarantee. Always review generated pull requests before merging.

What is a credit?+

Credits are pay-as-you-go. An AI scan costs 3 credits and a fix costs 5. They do not expire, and failed operations are refunded.

Are the prices shown with VAT?+

No. Prices exclude VAT, which is added at checkout where it applies, so you always see the final total before you pay.

Can I cancel Pro?+

Yes. Cancel from the billing page in the extension and keep Pro access until the end of the paid period.
